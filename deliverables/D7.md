# **1. Description**  
CircuitWorks is a 2D game that helps players learn about some engineering concepts such as factory simulation and automation alongside computer science principles. The value proposition of CircuitWorks is to provide a fun and interactive game envrionement where players can learn the engineering concpets at their own pace. The target user group of CircuitWorks is to those who are new or interested in learning about factory simulation, automation, and computer science.  
The MVP being tested includes saving, large world sizes, character customization, resource gathering, dynamic world generation, biomes, machine placement, player inventory, and player programming/typing. Some key features that are to be evaluated are the world generation, machine placement, inventory, resource gathering, and typing.

# **2. User Evaluation Script**  
**User Tasks**  
1.Make a new world  
2.Save the world  
3.Customize your character    
4.Explore the world  
5.Gather some resources  
6.Use your inventory to place a machine  

**Data Collection Methods**
The data collection will include error frequency, time to complete a task, and some debrifieng questions. Error frequency will be collected to understand if the game is not clear enough for them to complete a task. Time to complete a task will be collected to understand when a user is struggling to understand what they are seeing or if a user has a quick understanding at the game. Debriefing questions will give us insight as to what the user was thinking when playing the game.  

Note amount of times user asks clarifying questions or becomes stuck when playing the game.  

**Question Categories**  
On a scale of 1 - 10 how satisified are you with the world size?    
On a scale of 1 - 10 how satisified are you with the world biomes?   
On a scale of 1 - 10 was it difficult to explore the world?  
On a scale of 1 - 10 was it difficult to gather resources?  
On a scale of 1 - 10 how satisfied are you with the machine placement system?  
Open ended: Is the saving system useful to you?  
Open ended: Did you have trouble navigating the inventory?  
Open ended: What did you like most about the world you explored?  
How does the inventory ui compare to the main menu?  
Did you find the game controls useful?  
Compared to other games, how does CircuitWorks perform on your computer/machine?  

**Script Structure**  
Introduction (5 minutes):  
Provide value proposition, system description/overview and tasks the user will complete.  

Testing: 
Allow user to make a new world (10 Minutes).   
Data to be collected: time taken to create world, confusion and or hesitation.  

Allow user to explore the world (15 minutes).  
Data to be collected: Wether user asks for controls or finds them on their own, user notices world biomes user notices then collects resources.  

Allow user to view inventory (2 minutes).  
Data to be collected: User understands the types of items currently held in their inventory.  

Allow user to place a machine (5 minutes).  
Data to be collected: Time taken for user to make a succesfull placement  

Post Testing Questions (10 minutes).  
Ask the user questions defined above
