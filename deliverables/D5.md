# ** 1. Description**  
CircuitWorks is a 2Dgame that aims to teach players how to create circuits and program with them. Players can expect to find 
themselves in a dynamically generated world envionrment so that each player will have a world unique to them. Players will 
also be able to customize their character adding more personality to the way they play. Additionally, progress made in the game will be saved. 
Saving progress means that players will not have to worry their hard work will disapear. Instead, players can seamlessly continue
where they left off.  
  
CircuitWorks implements these features through several different ways. One way is by creating a clear, understandable UI when 
a user interacts with a feature. For example, to create a world players will be shown a UI with options to input a name, world seed
(used for dynamic world generation), and a difficulty setting. This gives players a easy way to get straight into the game without
needing to navigate a complex interface. Another example is seen in the world generation. The world generation is made through the 
random selection of different tiles. These tiles correspond to different envrionment types which are present when a player enters
the word.
