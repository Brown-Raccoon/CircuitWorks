# **1. Introduction**
**Description:** CircuitWorks is a 2D game that teaches players how to build circuits and how to program them to provide interactivity between them. The game features an envionrment players can explore with their own customised character. Worlds will be dynamically generated, provding different and unqiues envionrments for each player. Players can also save their progress to continue playing sometime else without the worry of losing progress  
**Value proposition:** CircuitWorks will help strengthen problem solving by allowing players to create and program circuits wrapped up in a fun game  
**MVP:** The MVP for CircuitWorks will contain buildable circuits that can be programmed using Python. Players can experiment with a few circuits and programming commands. In this release, players can explore a generated world and make their own character to roam the world

# **3. Automated Testing**
**Testing Framework:** CircuitWorks uses the **pytest** testing framework. It simplifies writing and running tests. It automatically finds and runs all of the game’s tests. It makes it easier for me to confirm that my changes didn't break game behavior and catch defects quickly.

**Code Being Tested**: The code tested by [test_game_logic.py](https://github.com/Brown-Raccoon/CircuitWorks/blob/main/tests/test_game_logic.py) is in [world_generation.py](https://github.com/Brown-Raccoon/CircuitWorks/blob/main/world_generation.py) and [inventory.py](https://github.com/Brown-Raccoon/CircuitWorks/blob/main/inventory.py).
- **World generation:** Test confirms that calling world generation with the same seed results in an identical game world and seed.
- **Adding inventory items:** Test verifies that calling inventory add on an item increments that item's inventory count.
- **Removing inventory items:** Test confirms that removing items inventory decreases the count correctly.
- **Insufficient inventory:** Test verifies that trying to remove more items than exist in the inventory doesn't change the count, and returns the expected result.
- **Invalid items:** Test checks that an inventory add of an invalid item is rejected.
- **Inventory data restoration:** Test ensures that inventory data can be exported to a dictionary and restored.

**Test Execution and Results**
- I ran the tests by typing the following command from the project root: `py -m pytest .\tests\test_game_logic.py -v`

# **4. Technology Stack**
**Technology Name** Python
**Description** Python is the primary programming language used to build the system and its requirements
**Justification** Python is a programming langauge that each of our team members are familiar with  

**Technology Name** Pygame
**Description** Pygame is a python library that is designed to make a 2D game. It has options for creating graphics such as text and buttons. Pygame also accepts user input which is necessary for a game. It can even be used to make a custom physics system
**Justification** Since the team was already familiary with Python, Pygame was a no brainer choice to help develop a 2D game. Using pygame with the knowledge of python made it easier to learn what pygame can do so that CircuitWorks becomes a 2D game 



# **5. Learning Strategy**
Resources used to learn pygame, game development in general are tutorial videos and the documentation website. The pygame documentation website is super helpful to start a 2D game project. Beyond learning the basics to start a 2D game, the website also a reference index showing the methods, functions, syntax and working examples to provide information as to how it works. Videos helped immensley by seeing the pygame functions translate into running the game.
