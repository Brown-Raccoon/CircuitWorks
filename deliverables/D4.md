# **1. Introduction**
**Description:** CircuitWorks is a 2D game that teaches players how to build circuits and how to program them to provide interactivity between them. The game features an envionrment players can explore with their own customised character. Worlds will be dynamically generated, provding different and unqiues envionrments for each player. Players can also save their progress to continue playing sometime else without the worry of losing progress  
**Value proposition:** CircuitWorks will help strengthen problem solving by allowing players to create and program circuits wrapped up in a fun game  
**MVP:** The MVP for CircuitWorks will contain buildable circuits that can be programmed using Python. Players can experiment with a few circuits and programming commands. In this release, players can explore a generated world and make their own character to roam the world

# **9. User Interface Design**
Design Approach: Our UI/UI methodology for this project focuses on making a clean, intuitive and user friendly interface that is accessible to new and experienced players alike. The primary goal is to reduce the amount of unneeded complexity while still being able to provide necessary functionality for more advanced gameplay and workflows.

One of our major design principles involves progressive disclosure, or where essential features/controls are presented in a clear way to new players, while more advanced features become available as players become more familiar with our game. This type of approach allows beginners to learn the mechanics without feeling overwhelmed but also allows room for them to learn and improve overtime.  

Additionally, we emphasize a type of visual consistency throughout the interface. We aim to make navigation predicable and reduce the time player spend searching for information or controls.

Usability Considerations:
- Simplicity and Clarity: We aim to avoid unnecessary visual clutter by prioritizing essential information and keeping menus organized.
- Intuitive Navigation: Common actions and frequently used features are designed to be easy to locate and access.
- Progressive Complexity: New players can interact with the game's basic systems without immediately needing to understand its more advanced mechanics.
- Visual Consistency: Consistent styling, layouts, and interface elements help create a cohesive experience.
