# **Positioning**
### *1.1 Problem Statement*
*The problem of the lack of learning in games affects the players; the impact of which is that players cannot sharpen their problem solving skills.*  

### *1.2 Product Position Statement*
*For players who want to discover learning machinery in CircuitWorks, a video game, that teachers players how to create machines and link circuits which supports problem solving skills; unlike Mega Factory Tycoon, our product does not rely on premade machines that do not require any input by the player to build.*  

### *1.3 Value propoosition and customer segment*
**Value proposition**: *CircuitWorks is a game that gives players the freedom to strengthen their problem solving skills by allowing them to create complex curcuits that supports custom programming within the game all wrapped up in a fun environment.* 

**Customer segment**: *People who play video games to enjoy learning by themselves or to teach a family member.*

# **2. Functional requirements**
1. Program Circuits with a microcontroller system
2. Connect circuits with eachother
3. Machines react to cuircuits
4. Machines produce items  
5. Gather resources
6. Process raw resources
7. Mine for raw materials
8. Create conveyor belt systems
Change direction, speed, item capacity, input.output
9. Generate power
10. Distribute electricity to machines
11. Control power with switches
12. Manage available power
13. Use sensors for items, storage, power, and machines
14. Provide an end goal A: buying, selling supplies, reach $1 million dollars
15. Proivide an end goal B: build a megaproject to connect a remote colony with the rest of humanity
16. Save the users progress  

# **3. Non-functional requirements**
1. Compatibility: Users can play the game on their personal desktop as well as on a laptop  
2. Usability: Users will spend no longer than 60 minutes when learning a new machine/circuit for the first time.  
3. Usability: Users will spend no longer than 2 seconds for a ui element to update such as an inventory. 
4. Usability: Users will locate all UI elemnts with 20 seconds after seeing the game UI and world UI for the first time.
5. Performance efficiency: The game will not drop below 60fps when running it on desktop or laptop computer with hardware from the last 5 years
6. Readability: UI text will be clear to read by making a large font with 60px size and avoiding collision with 80 pixels of space between other text  


# **4. MVP**  

The MVP for CircuitWorks will be a small interactive game where players can build circuits and write Python code to control them. The game will provide an environment where players can experiment with different circuit components and programming commands while building and expanding a factory.

This MVP is enough to validate the value proposition because it tests the main purpose of CircuitWorks: whether players can learn about circuits and Python while having fun and being creative. Players do not need a large world or many advanced features to test this. If they can create circuits, write code, build their factory, and experiment with different solutions, the MVP will show that CircuitWorks can combine learning, creativity, and gameplay.
